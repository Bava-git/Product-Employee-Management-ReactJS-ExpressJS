🧪 Cypress Core Commands
Navigation
cy.visit('/') → Visit base URL
cy.visit('/products') → Visit specific route
cy.reload() → Reload the page

Querying Elements
cy.get('.class') → Get element by class
cy.get('#id') → Get element by ID
cy.get('button') → Get element by tag
cy.contains('text') → Get element containing text
cy.find('selector') → Find child element

Actions
cy.click() → Click element
cy.type('Hello') → Type into input
cy.clear() → Clear input field
cy.select('Option') → Select dropdown option
cy.check() / cy.uncheck() → Check/uncheck checkbox
cy.scrollIntoView() → Scroll to element

Assertions
cy.should('be.visible') → Element is visible
cy.should('exist') → Element exists
cy.should('have.text', 'Hello') → Exact text match
cy.should('contain', 'Hello') → Partial text match
cy.should('have.value', '123') → Input value
cy.should('have.attr', 'href', '/home') → Attribute check

Waits & Timing
cy.wait(2000) → Wait 2 seconds
cy.wait('@alias') → Wait for network request
cy.intercept('GET', '/api/*').as('getData') → Stub/alias request

Misc
cy.url().should('include', '/products') → URL contains substring
cy.title().should('eq', 'Warehouse') → Page title check
cy.screenshot() → Take screenshot
cy.viewport(1280, 720) → Set viewport size

Usage
cy.xpath('//button[text()="Login"]') → Find button by text
cy.xpath('//input[@id="username"]') → Find input by attribute
cy.xpath('//div[contains(@class,"product")]') → Contains class
cy.xpath('//ul/li[1]') → First list item
cy.xpath('//a[@href="/home"]') → Anchor with href
cy.xpath('//table//tr[2]/td[3]') → Table cell

Combining with Assertions
cy.xpath('//h1').should('contain', 'Dashboard')
cy.xpath('//input[@type="email"]').should('be.visible')

⚡ Quick Comparison: CSS vs XPath
Task	CSS Selector	XPath Selector
By ID	#username	//input[@id="username"]
By Class	.btn-primary	//button[contains(@class,"btn-primary")]
By Text	cy.contains('Login')	//button[text()="Login"]
First Child	ul li:first-child	//ul/li[1]
Attribute	[href="/home"]	//a[@href="/home"]
